Уважаемый кандидат!
Мы рады пригласить вас пройти тестовое задание, которое поможет нам оценить ваши навыки в области хемоинформатики, ретросинтетического анализа и разработки метрик синтетической сложности.
Задание направлено на демонстрацию вашего умения:
• работать с генеративными библиотеками молекул,
• интегрировать open-source инструменты,
• разрабатывать и обосновывать числовые скоринговые функции.
На выполнение задания отводится 2 недели.

Описание задания
В рамках тестового задания вам необходимо:

1. Прогнать набор молекул через ретросинтетический движок AiZynthFinder (https://github.com/MolecularAI/aizynthfinder)
   o Вам будет предоставлен файл (output_500.sdf) с 500 сгенерированными молекулами.
   o Необходимо:
    настроить AiZynthFinder,
    выполнить ретросинтетический поиск для каждой молекулы,
2. Разработать числовую скоринговую функцию синтетической сложности
   На основе результатов работы AiZynthFinder необходимо предложить числовой скоринг синтетической доступности/сложности молекул.
   Требования:
   o Скоринг должен быть не бинарным, а численным (например, чем выше значение — тем сложнее синтез, или наоборот — оговорите явно направление шкалы).
   o В скоринг рекомендуется включить метрики, доступные в AiZynthFinder.
   o Молекулы, для которых AiZynthFinder не нашёл синтетического пути, также должны ранжироваться по этой метрике (не должно быть одинакового базового значения для молекул без синтетического путем)
   o Чётко обосновать принятую логику расчета скоринга.
3. Рассчитать скоринговую функцию для всего датасета и оценить скорость её вычисления
   o Необходимо:
    рассчитать выбранную/разработанную скоринговую функцию для всех 500 молекул,
    измерить и указать в отчёте время вычисления скоринга на весь датасет целиком.

Ожидаемые результаты

1. Файл с молекулами и рассчитанным скорингом
   • Необходимо предоставить SDF-файл, содержащий:
   o исходные структуры молекул,
   o численный скоринг синтетической сложности с понятным именем поля, например SynthScore
2. Код и инструкция по воспроизведению
   Необходимо предоставить:
   • Исходный код в виде:
   o одного или нескольких файлов .py и/или
   o Jupyter Notebook (.ipynb),
   • Код должен:
   o принимать на вход файл с молекулами
   o запускать AiZynthFinder и собирать результаты ретросинтеза, рассчитывать скоринговую функцию,
   o сохранять итоговый SDF (или другой формат) с рассчитанным скором.
   • Также необходимо приложить краткую инструкцию (в README или в отчёте) с описанием:
   o требований к окружению (Python-версия, зависимости),
   o установки AiZynthFinder (как вы это сделали),
   o команд/шагов для полного воспроизведения результатов.
3. Отчёт о проделанной работе
   Отчёт в формате .docx / .pdf должен включать:

1) Краткое описание подхода:
   o как вы интегрировали AiZynthFinder,
   o каков общий пайплайн от входного SDF до итогового скоринга,
   o какие допущения/ограничения вы ввели.
2) Описание скоринговой функции:
   o формальное определение / формула,
   o какие факторы учитываются (число шагов, наличие билдинг-блоков, статус ретросинтеза и др.),
   o как трактовать значение (что означает высокий/низкий скор).
3) Примеры и анализ:
   o несколько конкретных примеров молекул:
    «простых» (с низкой синтетической сложностью),
    «сложных»,
    без найденного пути — с разбором, почему так произошло по вашему мнению.
   o интерпретация скоринговых значений на этих примерах.
4) Оценка производительности:
   o время работы на датасете.
