# Репозиторий тестового задания ХимРар

Для выполнения задания реализована обёртка над библиотекой `aizynthfinder` для проведения параллельных вычислений. Интегрированы две внешних метрики: `RAscore`, `BR-SAScore`.

## Условия

Приведены условия выполнения задания и логичный способ решения.

1. _**Дан датасет молекул для оценки.**_

   Все молекулы приведены в формате SDF в 2D представлении. Значит, можно использовать напрямую SMILES без необходимости учитывать стереохимию (ярко видно на примере 27 из датасета)

2. _**Найти числовую функцию синтетической сложности и вычислить её на датасете.**_

   Так как некоторые молекулы могут не иметь синтетического пути, функция должна учитывать этот факт и не обнулять значение в таком случае. Очевидно, нужно учитывать не только сложность пути и количество узлов, но и стоимость прекурсоров.

   Логично использовать уже готовые метрики, которые были провалидированы на реальных датасетах и имеют оценку экспертов.

3. _**Не указаны: база данных, стоимость доступных реагентов, предпочтительные реакции**_

   Без этой информации можно использовать стандартный набор реагентов с их стоимостью. Например, тот, который скачивается вместе с библиотекой `aizynthfinder` (модели фильтрации и поиска пути, обученные на `UPSTO` базе данных реакций, `ZINC` - база прекурсоров).

   Исходя из этого, можно напрямую использовать метрику `RAscore`, которая обучалась на этих же данных. Подойдёт и любая другая, которая использует `aizynthfinder` в качестве отправной точки.

4. _**Нужны данные о скорости расчёта.**_

   Молекул много, значит нужно использовать параллельные вычисления. Нужно логирование или хотя бы сохранение времени расчёта для каждой отдельной молекулы.

## Структура

- `chemrar_retro` - Python библиотека-обёртка `aizynthfinder`
- `examples` - ноутбуки основных действий
  - `scoring.ipynb` - основной ноутбук, где проведены вычисления на датасете
  - `usage.ipynb` - ноутбук с примером использования и подводными камнями обёртки `aizynthfinder`
- `data` - модель и входной датасет
- `doc` - описание задачи
- `typings/rdkit-stubs` - stub файлы для `rdkit`, так как poetry устанавливает "плохую версию" rdkit, без нормальной поддержки типов (устанавливать из conda только rdkit не удобно - poetry перезаписывает conda библиотеки, а устанавливать все из conda нельзя - не все есть в conda-каналах)
- `report.pdf` - отчет о расчете датасета

## Установка

### Обычная

1. **Conda**

   Устанавливаем среду с Python=3.12, больше пакетов `conda` не понадобится. Однако установка `aizynthfinder` рекомендует устанавливать именно через conda (mamba), скорее всего, для дообучения моделей, что не используется здесь. Но на всякий случай лучше не отступать от официальной документации.

   ```
   conda create -p ./.venv -f conda.yml
   conda activate -p ./.venv
   ```

2. **Poetry**

   Установка зависимостей. `poetry` переписывает некоторые базовые компоненты для Python из conda. Но версии этих компонентов должны совпадать, поэтому ошибок не будет. `poetry` новой версии должен понять, что он находится внутри conda среды и не создавать новую.

   ```
   poetry install
   ```

### Другая

Можно установить `conda` не локально в проект, а в любую другую среду. Установка `poetry` остаётся такой же.

```
conda create -n chemrar_env -f conda.yml
conda activate chemrar_env
poetry install
```
